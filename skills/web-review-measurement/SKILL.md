# Web verification and measurement

Read `../web-review-loop/references/web-gates.md` and `../web-review-loop/references/web-lenses.md` lens 5. Inspect commands for side effects before execution; preserve privacy and mark unavailable checks SKIPPED. Record tool/version, route, device, test conditions, result and measurement. Distinguish field data at the 75th percentile from lab diagnostics; neither a Lighthouse score nor an arbitrary budget establishes standards conformance. Compare against an agreed project budget or the cited metric threshold and explain observed impact. For a full loop, return evidence, gaps and check results to the orchestrator.
