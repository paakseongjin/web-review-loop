# Web code and architecture review

Read `../web-review-loop/references/code-and-architecture.md` and `../web-review-loop/references/web-lenses.md` lenses 3 and 7. Trace the affected code and callers, trust boundaries and failure paths. Tie each finding to a file and line, trigger, evidence and actual or explicitly uncertain impact; cite applicable standards or version-specific official documentation when making normative claims. Do not call a design defect based solely on size, age, style choice or a second design system. For a full loop, return findings and gaps to the orchestrator; for a focused request, report only its scope.
