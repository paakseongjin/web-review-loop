# Web experience review

Read `../web-review-loop/references/web-lenses.md` lenses 1, 2, 4, 8, 9 and 10 and `../web-review-loop/references/web-gates.md` for execution and evidence. For a full loop, return findings and unverified coverage to the orchestrator; for a focused request, report only its scope.

Use actual route, state, viewport, keyboard steps, observed result and applicable success criterion or project requirement. At 320 CSS px equivalent check WCAG 2.2 SC 1.4.10 where applicable, including its two-dimensional-content exceptions; 390/768/1440 are representative layout checks, not proof of WCAG conformance. Do not assert visual readability or ease of use without an observable scenario. Test real submission only in an authorized safe environment. Record untested states.
